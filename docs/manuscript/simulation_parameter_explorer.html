CAUSANTA — Structural Parameter Explorer (drag the sliders)

The CAUSANTA simulator generates each tumor-cell phenotype from EGFR via fixed structural equations. Drag any coefficient and the response curves redraw live. The bottom-right panel runs a fresh in-browser Monte-Carlo population each time you drag, showing how the hypoxia→EGFR confounder (κhyp) biases a naive OLS slope while the ecDNA instrument (2SLS) stays unbiased — the core identification result of the paper.
